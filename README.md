# 奧瑞亞介面素材

介面用圖(dock 圖標、章節 UI、日誌書裝、入場精靈、成就、交易所、小劇場、世界門、特效、loading)。

走 jsdelivr:`https://cdn.jsdelivr.net/gh/nancywang3641/aurelia-ui-assets@main/aseets/<路徑>`

為什麼獨立一包:sound-files 有 1.2GB(音樂/場景圖),jsdelivr 抓不動,只能走 raw.githubusercontent,而 raw 會 429 限流把整個介面的圖打掛。

## 收錄範圍

只放「小張、常用」的介面圖,總量必須壓在 50MB 以下 —— 超過 jsdelivr 就會拒絕整個 repo(sound-files 1.2GB 正是因此抓不動)。

影片類特效(fx)、房間大底圖等仍留在 sound-files 走 raw。
